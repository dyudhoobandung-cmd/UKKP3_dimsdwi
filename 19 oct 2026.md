# Panduan Proyek Portal Layanan

Panduan ini menjelaskan struktur dan fungsi bagian proyek Laravel yang berkaitan
dengan portal login, pendaftaran, dan hak akses admin, petugas, serta customer.
File di `vendor/` dan konfigurasi bawaan Laravel tidak dijabarkan satu per satu
karena merupakan bagian dari framework atau dependency.

## 1. Gambaran aplikasi

Proyek menggunakan Laravel 13, PHP 8.3, SQLite, Blade, Tailwind CSS 4, dan Vite.
Pengguna dapat mendaftar sebagai customer, masuk, dan keluar. Setelah masuk,
pengguna diarahkan ke dashboard sesuai role. Pendaftaran umum tidak memberi
pilihan role admin atau petugas.

## 2. Alur aplikasi

1. Pengunjung membuka `/` dan melihat halaman beranda.
2. Pengunjung dapat membuka `/register` untuk membuat akun customer atau
   `/login` untuk masuk.
3. Form dikirim ke route `POST /register` atau `POST /login`.
4. `AuthController` memvalidasi data, membuat atau mengautentikasi pengguna,
   lalu memperbarui session.
5. Route `/dashboard` mengarahkan pengguna ke dashboard sesuai role.
6. Middleware `role` menolak pengguna yang mencoba membuka dashboard role lain
   dengan respons HTTP 403.
7. Form keluar mengirim `POST /logout`, mengakhiri session, dan mengarahkan
   pengguna kembali ke beranda.

## 3. File fitur dan kegunaannya

### Route dan pengaturan aplikasi

- `routes/web.php` — mendefinisikan beranda, halaman dan aksi login/daftar,
  logout, dashboard, nama route, middleware autentikasi, serta pembatasan role.
  Login juga dibatasi 5 percobaan per menit.
- `bootstrap/app.php` — mendaftarkan alias middleware `role` agar dapat
  digunakan pada route.
- `config/demo_accounts.php` — membaca email dan password akun demo dari
  variabel environment melalui konfigurasi Laravel.
- `.env` — konfigurasi lokal mesin, termasuk kredensial demo lokal. File ini
  tidak dibagikan sebagai konfigurasi untuk production.
- `.env.example` — contoh konfigurasi environment. Kredensial demo yang
  dicantumkan ditujukan untuk development lokal.

### Controller dan middleware

- `app/Http/Controllers/AuthController.php` — menampilkan form login/daftar;
  memvalidasi kredensial dan data pendaftaran; membuat akun customer;
  memproses login, regenerasi session, dan logout.
- `app/Http/Controllers/DashboardController.php` — memilih dashboard berdasarkan
  role dan menyediakan label serta keterangan yang ditampilkan.
- `app/Http/Middleware/EnsureUserHasRole.php` — memastikan pengguna yang masuk
  memiliki salah satu role yang diizinkan route.
- `app/Http/Controllers/Controller.php` — controller dasar Laravel yang dapat
  digunakan oleh controller aplikasi.

### Model dan database

- `app/Models/User.php` — model pengguna yang dipakai untuk autentikasi.
  Atribut nama, email, password, dan role dapat diisi oleh aplikasi; password
  dan token tidak ditampilkan saat model diserialisasi. Password di-hash.
- `database/migrations/0001_01_01_000000_create_users_table.php` — membuat tabel
  pengguna, token reset password, dan session.
- `database/migrations/2026_10_19_013747_add_role_to_users_table.php` —
  menambahkan kolom role berindeks, dengan nilai default `customer`, sehingga
  akun yang sudah ada juga memiliki role.
- `database/factories/UserFactory.php` — menyediakan data pengguna untuk test
  dan pengembangan; role default factory adalah customer.
- `database/seeders/DatabaseSeeder.php` — membuat akun demo yang dikonfigurasi
  saat environment `local` atau `testing`. Akun dibuat dengan `firstOrCreate`,
  jadi menjalankan seeder lagi tidak mengganti password akun yang sudah ada.
- `database/database.sqlite` — file database SQLite lokal proyek.
- `database/migrations/0001_01_01_000001_create_cache_table.php` dan
  `database/migrations/0001_01_01_000002_create_jobs_table.php` — migration
  bawaan Laravel untuk cache dan antrean pekerjaan.

### Tampilan

- `resources/views/layouts/app.blade.php` — layout bersama, judul halaman,
  navigasi, tombol masuk/daftar atau nama pengguna/tombol keluar, dan footer.
- `resources/views/welcome.blade.php` — halaman beranda dan tautan menuju
  login atau pendaftaran.
- `resources/views/auth/login.blade.php` — form login, opsi ingat saya, dan
  tampilan pesan validasi.
- `resources/views/auth/register.blade.php` — form pendaftaran nama, email,
  password, dan konfirmasi password. Form tidak menyediakan pemilihan role.
- `resources/views/dashboard.blade.php` — dashboard ringkas dengan nama,
  email, dan role pengguna yang sedang masuk.
- `resources/css/app.css` — entry point CSS Tailwind dan konfigurasi font
  aplikasi.
- `resources/js/app.js` — entry point JavaScript aplikasi.

### Pengujian

- `tests/Feature/AuthenticationAndRolesTest.php` — menguji halaman publik,
  pendaftaran customer, validasi konfirmasi password, login, logout, akses
  dashboard sesuai role, serta penolakan akses antar-role.
- `tests/Feature/ExampleTest.php` — contoh test feature bawaan Laravel.
- `tests/Unit/ExampleTest.php` — contoh test unit bawaan Laravel.
- `phpunit.xml` — konfigurasi PHPUnit; test memakai database SQLite sementara
  di memori.

### Dependency dan build aset

- `composer.json` dan `composer.lock` — daftar serta versi dependency PHP
  Laravel, Boost, dan alat pengembangan/test.
- `package.json` — dependency frontend dan perintah `npm run build` serta
  `npm run dev`.
- `vite.config.js` — konfigurasi integrasi Vite dengan Laravel.

## 4. Role dan dashboard

| Role | Route dashboard | Keterangan |
| --- | --- | --- |
| `admin` | `/admin/dashboard` | Dashboard administrator |
| `petugas` | `/petugas/dashboard` | Dashboard petugas |
| `customer` | `/customer/dashboard` | Dashboard customer |

Role customer diberikan oleh proses pendaftaran. Role admin dan petugas harus
diberikan oleh pengelola melalui akun yang dikonfigurasi atau proses administrasi
yang tepercaya; jangan menambahkan input role ke form pendaftaran publik.

## 5. Menjalankan proyek lokal

Jalankan perintah berikut dari folder proyek:

```powershell
composer install
npm.cmd install
php artisan migrate
php artisan db:seed
npm.cmd run build
php artisan serve
```

Buka `http://127.0.0.1:8000` di browser. Halaman login tersedia di
`http://127.0.0.1:8000/login`, sedangkan pendaftaran tersedia di
`http://127.0.0.1:8000/register`.

Contoh akun admin lokal yang dikonfigurasi untuk proyek ini:

- Email: `admin@example.com`
- Password awal: `admin123`

Akun demo petugas dapat diatur melalui `DEMO_PETUGAS_EMAIL` dan
`DEMO_PETUGAS_PASSWORD`. Untuk menjalankan seeder dengan akun demo, pastikan
kedua nilai bagi role yang ingin dibuat sudah terisi di `.env`.

`firstOrCreate` hanya membuat akun jika email belum terdaftar. Jika akun admin
sudah pernah dibuat lalu password pada `.env` diganti, jalankan proses reset
password yang tepercaya atau perbarui akun secara terpisah; mengulang seeder
tidak akan mengganti password lama. Jangan gunakan password demo pada server
publik; buat kredensial baru yang kuat dan lindungi file `.env`.

## 6. Memeriksa proyek

```powershell
php artisan route:list
php artisan test
vendor\bin\pint --test
npm.cmd run build
```

Test feature penting untuk alur autentikasi dan role berada di
`tests/Feature/AuthenticationAndRolesTest.php`.
